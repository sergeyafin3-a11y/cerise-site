# Cerise — сайт

Главная страница приложения Cerise: приложение для взрослых пар (18+). Русский и английский.

Сайт: https://sergeyafin3-a11y.github.io/cerise-site/

В репозитории только страница, картинки и шрифт Pangolin (лицензия — `fonts/OFL-pangolin.txt`). Политика приватности, условия и удаление аккаунта лежат на https://cerise-app.com. Значки App Store и Google Play — официальные, перерисовывать их нельзя.
